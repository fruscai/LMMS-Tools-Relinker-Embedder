LMMS Sample Embedder

Embeds sample audio into LMMS project files

Runs entirely in your browser
Writes sample audio into the project file, so it plays without the original audio files. All other files are copied unchanged.
About

This tool processes files locally in your browser and does not upload anything. It writes the audio of each sample into one LMMS project file, so the project plays on any machine with stock LMMS 1.3, with no sample folders, no relinking and nothing extra to send. It takes one final project at a time.

How to start
  1. Drag your final project file into the drop zone below, or click the Choose project file button. One .mmpz or .mmp.
  2. Click the Connect gig folder button and select your LMMS gig folder, for example Documents/lmms/samples/gig. Chrome remembers it after the first time. Brave and Safari ask again on each visit, and their dialog says "upload" even though nothing leaves your machine.
  3. If a sample lives somewhere other than the gig folder, click the Add a sample folder button and select that folder as well.
  4. Click the Check button. This is a preview only, and nothing is written yet. The table shows how many samples will be embedded and names anything that could not be found.
  5. If a reference matches more than one file, the tool lists the candidates and waits for you to pick the one you meant. It never guesses.
  6. Click the Embed & save button. The finished project downloads automatically as one -EMBEDDED file. If anything fails, no file is produced and the reason is shown.
  7. Check your work. Open the downloaded project in LMMS and make sure every file loads. To prove the audio really travelled, move the audio files to the trash or out of the gig folder and open the project again. Every sample should still be there.

⚠️ A sample that cannot be found keeps its original path and is named in the report. The rest still embed, and the project still opens.

⚠️ Please do not modify this code or its functionality. If you find a bug, DM me so I can verify it and work on a fix for everyone.
